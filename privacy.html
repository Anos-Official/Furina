Furina — Privacy Policy

Any resemblance of name or personality to existing characters is for entertainment purposes only.

Overview

This policy explains what information the Furina Discord bot processes, why, and where it goes. Furina is a hobby project run by an individual, not a company, and does not sell or monetize any data it processes. See also the Terms of Service.

What information is processed

Data Why Stored long-term?
Text of recent messages in channels the bot can see To decide whether to reply, and to generate a fitting in-character reply No — kept in memory only while the bot is running, cleared on restart
Display names visible in those messages Included as context so replies address the right person / conversation No
Discord user or channel IDs Technical necessity of using the Discord API (e.g. knowing where to reply) No — not logged beyond normal runtime operation

Furina does not access messages in channels it hasn't been given permission to view, does not read direct messages unless directly messaged, and does not collect emails, IPs, payment information, or any data beyond what's described above.

Third-party sharing

To generate replies, Furina sends a snippet of recent chat text to a third-party AI inference provider (by default, Groq) for processing. This is the only third party that receives message content.

  • Groq processes the text to generate a response, which Furina then posts back to Discord.
  • Handling of that data on Groq's end is governed by Groq's own privacy policy and terms, not by the bot owner.
  • No data is sold, shared with advertisers, or used for purposes unrelated to generating the bot's replies.

Data retention

Furina does not use a database and does not permanently log chat content. Recent messages are held only in the bot's active memory to provide conversational context, and are lost whenever the bot restarts. The bot owner does not manually review chat history beyond what's needed to debug technical issues in the moment.

Security

The bot's credentials (its Discord token and AI provider API key) are kept private and are not exposed in the bot's code or outputs. As with any bot, message content passes over the internet to Discord's and the AI provider's servers as part of normal operation.

Children's privacy

Furina is not directed at children and does not knowingly collect data from users. Use of Discord itself is subject to Discord's own age requirements and terms.

Your choices

  • Server admins can remove Furina from a server at any time, which immediately stops it from reading any further messages there.
  • Since no message content is stored beyond the bot's runtime memory, there is no persistent personal data to request deletion of once the bot is removed or restarted.
  • You can avoid interacting with the bot by not messaging in channels it's active in, or by asking a server admin to restrict which channels it can see.

Changes to this policy

This policy may be updated as the bot's functionality changes (for example, if a database is added for new features). Continued use of the bot after an update implies acceptance of the current version of this policy.
